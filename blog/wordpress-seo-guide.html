وردپرس

راهنمای کامل سئو وردپرس از صفر تا صد

۱۰ آذر ۱۴۰۳ • ۱۲ دقیقه مطالعه • تیم سئو تور

وردپرس با سهم بیش از ۴۳ درصد از کل وب‌سایت‌های جهان، محبوب‌ترین سیستم مدیریت محتواست. یکی از دلایل اصلی این محبوبیت، سازگاری عالی وردپرس با سئو است. با این حال، وردپرس به‌تنهایی برای رتبه‌بندی در گوگل کافی نیست؛ شما باید تنظیمات درست، افزونه‌های مناسب و بهینه‌سازی‌های فنی را پیاده کنید. در این راهنمای جامع، تمام مراحل سئو وردپرس از نصب اولیه تا تکنیک‌های پیشرفته را قدم‌به‌قدم پوشش می‌دهیم.

وردپرس از جعبه ۳۰ تا ۴۰ درصد آماده سئو است. ۶۰ تا ۷۰ درصد بقیه به تنظیمات، افزونه‌ها و بهینه‌سازی‌های شما بستگی دارد. این راهنما کمک می‌کند آن ۶۰ تا ۷۰ درصد را به‌درستی پیاده کنید.

۱. تنظیمات اولیه وردپرس

قبل از نصب هر افزونه‌ای، باید تنظیمات پیش‌فرض وردپرس را بهینه کنید. اولین و مهم‌ترین کار، تنظیم Permalink است. به مسیر «تنظیمات → پیوندها» بروید و گزینه «نام نوشته» (Post Name) را انتخاب کنید. این کار باعث می‌شود URL صفحات شما به‌جای ?p=123 به‌صورت /blog/wordpress-seo-guide در بیاید که هم سئو‌فرندلی‌تر است و هم برای کاربر خواناتر.

در بخش «تنظیمات → خواندن» باید مطمئن شوید گزینه «جلوگیری از ایندکس شدن سایت توسط موتورهای جستجو» غیرفعال است. این گزینه اغلب در سایت‌های در حال توسعه فعال می‌ماند و فراموش می‌شود. در همین بخش، تعداد پست‌های صفحه اصلی را روی ۱۰ تنظیم کنید تا سرعت بارگذاری بالا برود. همچنین اگر سایت شما تک‌نویسنده است، در بخش «تنظیمات → گفتگوها»، گزینه نظرات روی لینک‌های پیوست (pingback و trackback) را غیرفعال کنید تا از اسپم و حملات DDoS جلوگیری شود.

در بخش «تنظیمات → حریم خصوصی» یک صفحه حریم خصوصی بسازید و آن را به وردپرس معرفی کنید. این کار هم از نظر قانونی (قانون GDPR و قانون جرایم رایانه‌ای ایران) لازم است و هم از نظر سئو، اعتماد گوگل را جلب می‌کند. در نهایت، در بخش «تنظیمات → عمومی»، عنوان سایت و معرفی کوتاه را با کلمه کلیدی اصلی بنویسید. این موارد در نوار عنوان مرورگر و متاتگ‌ها استفاده می‌شوند.

۲. انتخاب قالب سئو‌فرندلی

قالب وردپرس زیربنای سئو شماست. یک قالب بد می‌تواند تمام تلاش‌های سئو شما را بی‌اثر کند. قالب باید سبک، سریع، واکنش‌گرا (Responsive) و کدنویسی تمیز داشته باشد. از قالب‌های پر از افکت‌های بصری، اسلایدرهای سنگین و انیمیشن‌های غیرضروری پرهیز کنید. هر کیلوبایت اضافی، از سرعت سایت می‌کاهد.

معیارهای قالب سئو‌فرندلی

  • سرعت بارگذاری: دمو قالب را در PageSpeed Insights تست کنید؛ نمره باید حداقل ۸۰ باشد.
  • کد معتبر W3C: HTML و CSS قالب باید بدون خطا باشند.
  • سازگاری با موبایل: قالب باید Mobile-Friendly باشد.
  • Schema Markup داخلی: قالب‌های مدرن Schema را به‌صورت پیش‌فرض دارند.
  • به‌روزرسانی منظم: قالب باید حداقل هر سه ماه به‌روز شود.
  • پشتیبانی از RTL: برای سایت‌های فارسی ضروری است.

از قالب‌های پیشنهادی و سئو‌فرندلی می‌توان به GeneratePress، Astra، Kadence، Blocksy و OceanWP اشاره کرد. این قالب‌ها سبک هستند (کمتر از ۱۰ کیلوبایت CSS)، با Gutenberg سازگارند و نسخه رایگان هم دارند. قالب‌های پریمیوم مانند Avada و Enfold ممکن است امکانات زیادی داشته باشند اما سرعت را به‌شدت پایین می‌آورند. اگر قالبی انتخاب می‌کنید که از Page Builderهایی مانند Elementor یا WPBakery استفاده می‌کند، حتماً نسخه بهینه آن را نصب کنید و از ویجت‌های کمتر استفاده کنید.

۳. مقایسه Yoast SEO vs Rank Math

دو افزونه سئو غالب در وردپرس، Yoast SEO و Rank Math هستند. هر دو کار اصلی را انجام می‌دهند: متاتگ‌ها، Sitemap، Schema، Breadcrumbs و تحلیل محتوا. اما تفاوت‌های مهمی دارند که باید قبل از انتخاب بدانید.

ویژگی Yoast SEO Rank Math
قیمت نسخه رایگان محدود گسترده
تعداد Schema در رایگان ۳ نوع ۱۳+ نوع
تحلیل کلمه کلیدی ۱ کلمه چند کلمه
اتصال به Search Console فقط پریمیوم رایگان
رابط کاربری ساده پیچیده‌تر اما کامل‌تر
بهینه‌سازی سرعت خوب عالی
پشتیبانی از RTL خوب خوب
قیمت نسخه پریمیوم سالانه ۹۹ یورو ۵۹ دلار

تیم سئو تور برای اکثر پروژه‌ها Rank Math را توصیه می‌کند، زیرا در نسخه رایگان امکانات بیشتری دارد و گزینه مقرون‌به‌صرفه‌تری است. اما اگر سایت شما قبلاً با Yoast ساخته شده و مشکلی ندارد، نیازی به مهاجرت نیست. توجه کنید که هرگز Yoast و Rank Math را هم‌زمان فعال نکنید؛ این کار باعث تداخل و خرابی می‌شود.

۴. بهینه‌سازی سرعت وردپرس

سرعت یکی از مهم‌ترین فاکتورهای رتبه‌بندی است و وردپرس به‌طور پیش‌فرض می‌تواند کند باشد. برای بهینه‌سازی سرعت وردپرس، چهار محور اصلی را باید پوشش دهید: Caching، CDN، بهینه‌سازی تصاویر و کاهش درخواست‌های HTTP.

افزونه‌های Caching پیشنهادی

  • WP Rocket (پولی): بهترین افزونه کش با تنظیمات پیش‌فرض عالی. قیمت ۵۹ دلار در سال.
  • W3 Total Cache (رایگان): قدرتمند اما نیاز به تنظیمات手动 دارد.
  • LiteSpeed Cache (رایگان): اگر سرور شما LiteSpeed است، بهترین گزینه است.
  • WP Super Cache (رایگان): ساده و سبک، مناسب سایت‌های کوچک.

پس از فعال‌سازی کش، باید یک CDN مانند Cloudflare (رایگان)، ArvanCloud یا CloudFront نصب کنید. CDN محتوای استاتیک سایت شما (تصاویر، CSS، JS) را در سرورهای مختلف در سراسر جهان ذخیره می‌کند و به کاربر نزدیک‌ترین سرور را می‌دهد. این کار می‌تواند سرعت بارگذاری را تا ۵۰ درصد بهبود دهد. در ایران ArvanCloud بهترین انتخاب است زیرا سرورهای داخلی دارد.

برای بهینه‌سازی تصاویر از افزونه‌هایی مانند ShortPixel، Smush یا Imagify استفاده کنید. این افزونه‌ها تصاویر را به‌صورت خودکار فشرده می‌کنند و نسخه WebP می‌سازند. فرمت WebP می‌تواند حجم تصاویر را تا ۳۰ درصد نسبت به JPEG و ۸۰ درصد نسبت به PNG کاهش دهد. همچنین قابلیت Lazy Load را فعال کنید تا تصاویری که در viewport نیستند، بارگذاری نشوند.

۵. بهبود Core Web Vitals در وردپرس

Core Web Vitals سه معیار کلیدی گوگل برای سنجش تجربه کاربری است: LCP، INP و CLS. در وردپرس، این معیارها اغلب به‌دلیل تصاویر بزرگ، اسکریپت‌های افزونه‌ها و عدم بهینه‌سازی قالب ضعیف هستند. برای بهبود LCP، تصویر شاخص را قبل از fold قرار دهید و آن را preload کنید. همچنین از loading="eager" برای تصویر LCP استفاده کنید (نه lazy).

برای بهبود INP، افزونه‌های غیرضروری را حذف کنید. هر افزونه JavaScript اضافه می‌کند که تعامل کاربر را کند می‌کند. ابزار Query Monitor را نصب کنید تا ببینید کدام افزونه‌ها بیشترین تأثیر منفی را دارند. برای بهبود CLS، حتماً ابعاد تصاویر (width و height) را مشخص کنید، فضای رزرو شده برای تبلیغات تعیین کنید و از فونت‌های Web-safe استفاده کنید. اگر فونت سفارشی دارید، از font-display: swap استفاده کنید.

افزونه‌های مفید برای Core Web Vitals شامل Perfmatters، FlyingPress و WP Rocket هستند. این افزونه‌ها Delay JavaScript، Remove Unused CSS و Critical CSS را به‌صورت خودکار انجام می‌دهند. همچنین قابلیت Delay JS باعث می‌شود اسکریپت‌های غیرضروری تا تعامل کاربر بارگذاری نشوند که INP را به‌شدت بهبود می‌دهد. در نهایت، نمره سایت خود را در PageSpeed Insights و Search Console بخش Core Web Vitals پایش کنید.

۶. سئو ووکامرس

ووکامرس محبوب‌ترین افزونه فروشگاه‌ساز وردپرس است و سهم ۲۸ درصدی از کل فروشگاه‌های اینترنتی دارد. سئو ووکامرس تفاوت‌های مهمی با سئو وبلاگ دارد. اول، هر محصول باید عنوان، توضیحات و تصاویر منحصربه‌فرد داشته باشد. از توضیحات کوتاه و تکراری پرهیز کنید. دوم، از Schema Product استفاده کنید تا قیمت، موجودی و امتیاز محصول در نتایج جستجو نمایش داده شود. Rank Math و Yoast هر دو این Schema را پشتیبانی می‌کنند.

صفحات دسته‌بندی محصول باید توضیحات کوتاه (حداقل ۲۰۰ کلمه) داشته باشند تا از نظر سئو ارزشمند باشند. از Canonical برای صفحات فیلتر شده استفاده کنید تا محتوای تکراری نسازید. همچنین URLهای فیلتر را با پارامتر ?orderby یا ?filter مدیریت کنید و در Search Console تنظیم کنید که گوگل فقط نسخه اصلی را ایندکس کند.

صفحه پرداخت و سبد خرید را noindex کنید تا ایندکس نشوند. همچنین صفحات «حساب من»، «ثبت‌نام» و «تشکر از خرید» را noindex کنید. برای بهبود سرعت ووکامرس، از افزونه‌های بهینه‌سازی مخصوص مانند WooCommerce Optimizer و Cart All In One استفاده کنید. تعداد محصول در صفحه را روی ۱۲ یا ۲۴ تنظیم کنید (نه ۴۸ یا ۹۶) و از پاگینیشن به‌جای infinite scroll استفاده کنید.

۷. بهینه‌سازی دیتابیس وردپرس

دیتابیس وردپرس با گذشت زمان پر از داده‌های غیرضروری می‌شود: بازبینی‌های پست (Revisions)، draftهای قدیمی، spamها، transients منقضی شده و... این داده‌ها دیتابیس را سنگین می‌کنند و سرعت query را پایین می‌آورند. برای بهینه‌سازی دیتابیس از افزونه WP-Optimize استفاده کنید که می‌تواند بازبینی‌ها، نظرات spam و transients را با یک کلیک پاک کند.

توصیه می‌شود تعداد بازبینی‌های هر پست را محدود کنید. در فایل wp-config.php این خط را اضافه کنید:

define('WP_POST_REVISIONS', 3);
define('AUTOSAVE_INTERVAL', 300); // 5 minutes

این کار باعث می‌شود وردپرس فقط ۳ بازبینی برای هر پست نگه دارد و هر ۵ دقیقه یک‌بار autosave انجام دهد. همچنین افزونه Index AUTO و MySQL Tuner می‌توانند ایندکس‌های دیتابیس را بهینه کنند. اگر سایت شما بزرگ است (بیش از ۱۰ هزار پست)، از سرورهای با MariaDB 10.6+ و InnoDB استفاده کنید. همچنین قابلیت Object Cache با Redis یا Memcached را فعال کنید تا queryهای تکراری کش شوند.

۸. امنیت وردپرس و تأثیر روی سئو

سایت‌های هک‌شده می‌توانند به‌سرعت از نتایج جستجو حذف شوند. گوگل اگر بفهمد سایت شما بدافزار دارد، هشدار «This site may be hacked» را در نتایج نمایش می‌دهد که می‌تواند ۹۰ درصد ترافیک شما را نابود کند. امنیت وردپرس شامل چند لایه است: سرور، فایل‌های وردپرس، دیتابیس و افزونه‌ها.

اقدامات امنیتی ضروری

  • پسورد پیچیده برای کاربر admin و غیرفعال‌سازی ویرایشگر فایل از داخل پنل.
  • استفاده از افزونه Wordfence یا Sucuri برای فایروال و اسکن بدافزار.
  • به‌روزرسانی مداوم وردپرس، قالب و افزونه‌ها.
  • حذف افزونه‌ها و قالب‌های غیرفعال.
  • تغییر پیشوند جدول‌های دیتابیس از wp_ به یک پیشوند دلخواه.
  • مخفی کردن نسخه وردپرس در head.
  • فعال‌سازی Two-Factor Authentication (با افزونه Wordfence Login Security).
  • پشتیبان‌گیری منظم روزانه با افزونه UpdraftPlus.

علاوه بر این، HTTP Security Headers را با افزونه Headers Security یا از طریق فایل .htaccess فعال کنید. این هدرها شامل X-Frame-Options، X-Content-Type-Options، Strict-Transport-Security و Content-Security-Policy هستند. گوگل این هدرها را به‌عنوان سیگنال اعتماد در نظر می‌گیرد. در نهایت، سایت خود را در Search Console بخش Security & Manual Actions پایش کنید تا در صورت هک شدن، سریعاً مطلع شوید.

۹. افزونه‌های ضروری سئو وردپرس

علاوه بر افزونه اصلی سئو (Yoast یا Rank Math)، چند افزونه دیگر برای سئو وردپرس ضروری هستند:

افزونه کاربرد نسخه
Rank Math / Yoast سئو On-Page، Schema، Sitemap رایگان کافی است
WP Rocket / LiteSpeed Cache کش و بهینه‌سازی سرعت پولی/رایگان
ShortPixel / Smush فشرده‌سازی تصاویر و WebP رایگان کافی است
WP-Optimize بهینه‌سازی دیتابیس رایگان
Wordfence / Sucuri امنیت و فایروال رایگان کافی است
Redirection مدیریت Redirect 301 رایگان
Query Monitor عیب‌یابی و تحلیل کارایی رایگان
UpdraftPlus پشتیبان‌گیری خودکار رایگان کافی است

توجه کنید که هر افزونه‌ای که اضافه می‌کنید، سرعت را تا حدی کاهش می‌دهد. هدف باید نصب حداکثر ۱۰ تا ۱۵ افزونه باشد و هر افزونه‌ای که استفاده نمی‌کنید را حذف کنید. افزونه‌های غیرفعال هم می‌توانند آسیب‌پذیری امنیتی ایجاد کنند، پس حذف کامل آن‌ها ضروری است.

۱۰. اشتباهات رایج سئو وردپرس

در سال‌ها فعالیت، اشتباهاتی را بارها در سایت‌های وردپرسی دیده‌ایم که به‌شدت به سئو آسیب می‌رسانند. آگاهی از این اشتباهات به شما کمک می‌کند از آن‌ها دوری کنید:

  1. استفاده از چند افزونه سئو هم‌زمان: Yoast، Rank Math و All in One SEO را هم‌زمان فعال نکنید. این کار باعث تداخل متاتگ‌ها و Sitemap می‌شود.
  2. عدم تنظیم Permalink: سایت‌هایی که هنوز URLهای ?p=123 دارند، سئوی ضعیفی دارند.
  3. تصاویر بدون Alt: موتورهای جستجو نمی‌توانند تصاویر را بدون Alt درک کنند.
  4. دسته‌بندی و تگ تکراری: اگر یک پست را هم در دسته «اخبار» و هم در تگ «اخبار» قرار دهید، محتوای تکراری می‌سازید.
  5. نادیده گرفتن Breadcrumbs: Breadcrumbs هم برای کاربر و هم برای سئو مهم است.
  6. تولید خودکار متا Description: متای خودکار اغلب شامل کلمه کلیدی نیست و CTR پایینی دارد.
  7. نصب قالب‌های nulled (قفل‌شکسته): این قالب‌ها اغلب شامل بدافزار هستند.
  8. عدم بهینه‌سازی دیتابیس: دیتابیس سنگین، سرعت کل سایت را پایین می‌آورد.
  9. استفاده از Elementor با ویجت زیاد: هر ویجت JavaScript و CSS اضافه می‌کند.
  10. عدم پشتیبان‌گیری: اگر سایت هک شود یا خراب شود، بدون بک‌آپ همه چیز از دست می‌رود.

چک‌لیست عملی سئو وردپرس

این چک‌لیست را به‌عنوان چک‌لیست ماهیانه خود نگه دارید:

  • ✅ Permalink روی Post Name تنظیم شده باشد.
  • ✅ فقط یک افزونه سئو (Yoast یا Rank Math) فعال باشد.
